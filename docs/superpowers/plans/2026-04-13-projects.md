# Aurora Chat Projects Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the raw CWD picker with first-class Projects — named folders with git awareness, session grouping, and a universal project switcher.

**Architecture:** Rust backend stores projects in Aurora's own `projects.json` (via Tauri `app_data_dir()`), provides git info commands. Frontend has a Zustand project store, a reusable ProjectSwitcher dropdown component, and a revamped sidebar with project header + time-grouped sessions.

**Tech Stack:** Rust (uuid, serde_json, tokio), React + Zustand, Tauri v2 IPC

**Spec:** `docs/superpowers/specs/2026-04-13-projects-design.md`

The module stores projects in Tauri's `app_data_dir()` as `projects.json`. Key types:

```rust
// src-tauri/src/projects.rs

use serde::{Deserialize, Serialize};
use std::collections::HashMap;
use std::path::PathBuf;
use tokio::sync::Mutex as TokioMutex;

pub struct ProjectLock(pub TokioMutex<()>);

#[derive(Clone, Serialize, Deserialize)]
pub struct Project {
    pub id: String,
    pub name: String,
    pub path: String,
    pub created_at: u64,       // epoch ms
    pub last_opened_at: u64,   // epoch ms
    pub pinned: bool,
}

#[derive(Clone, Serialize, Deserialize)]
pub struct GitInfo {
    pub branch: Option<String>,
    pub dirty: bool,
    pub remote: Option<String>,
}

#[derive(Clone, Serialize, Deserialize)]
pub struct DetectedProject {
    pub git_root: String,
    pub suggested_name: String,
    pub git_info: GitInfo,
}

#[derive(Clone, Serialize, Deserialize, Default)]
pub struct ProjectData {
    pub projects: Vec<Project>,
    pub session_projects: HashMap<String, String>, // session_id -> project_id
    pub active_project_id: Option<String>,
}

const SCRATCHPAD_ID: &str = "scratchpad";
```

Storage functions:
- `data_dir(app: &AppHandle) -> PathBuf` — uses `app.path().app_data_dir()`, creates dir if needed
- `data_path(app) -> PathBuf` — `data_dir / "projects.json"`
- `read_data(app) -> ProjectData` — reads JSON, returns default if missing
- `write_data(app, data)` — atomic write (temp + rename + chmod 0600)

Project CRUD:
- `list_projects(app)` — read + return projects vec
- `add_project(app, path, name)` — validate `.git` exists, generate UUID, append, write
- `remove_project(app, id)` — remove from projects + clean session_projects entries, write
- `update_project(app, id, name, pinned)` — update fields, write
- `set_active_project(app, id)` — update active_project_id + last_opened_at, write

Session mapping:
- `assign_session(app, session_id, project_id)` — add to session_projects, write
- `get_sessions_for_project(app, project_id, limit)` — read all sessions from hermes DB (existing `list_sessions`), filter by session_projects map client-side

Git:
- `get_git_info(path)` — `git -C <path> rev-parse --abbrev-ref HEAD` + `git -C <path> status --porcelain` + `git -C <path> remote get-url origin`. Validate path against shell metacharacters first.
- `detect_project(path)` — walk up from path looking for `.git` dir (stop at filesystem root). Return git root, suggested name (basename), git info.

Tests: YAML parsing not needed (it's JSON), but test:
- Project CRUD round-trip with temp dir
- Git info parsing (mock git output)
- detect_project walking up directories
- Session-project mapping filter logic
- Path validation (shell metacharacters rejected)

## Task 3: Time Grouping Helper

**Files:**
- Create: `v2/src/utils/time-groups.ts`

- [ ] **Step 1: Create the helper**

```typescript
// v2/src/utils/time-groups.ts

function startOfDay(ts: number): number {
  const d = new Date(ts)
  d.setHours(0, 0, 0, 0)
  return d.getTime()
}

export interface TimeGroup<T> {
  label: string
  items: T[]
}

export function groupByTime<T>(
  items: T[],
  getTimestamp: (item: T) => number
): TimeGroup<T>[] {
  const now = Date.now()
  const todayStart = startOfDay(now)
  const yesterdayStart = startOfDay(now - 86400000)
  const weekStart = startOfDay(now - 7 * 86400000)

  const groups: TimeGroup<T>[] = [
    { label: 'Today', items: items.filter(i => getTimestamp(i) >= todayStart) },
    { label: 'Yesterday', items: items.filter(i => getTimestamp(i) >= yesterdayStart && getTimestamp(i) < todayStart) },
    { label: 'This Week', items: items.filter(i => getTimestamp(i) >= weekStart && getTimestamp(i) < yesterdayStart) },
    { label: 'Older', items: items.filter(i => getTimestamp(i) < weekStart) },
  ]

  return groups.filter(g => g.items.length > 0)
}
```

- [ ] **Step 1: Replace CWD startup with project startup in useAcpEvents.ts**

Remove the existing `get_launch_cwd` + `acp_new_session` startup logic (lines 35-53). Replace with:

```typescript
// Project-aware startup
invoke<string>('get_launch_cwd').then(async (launchCwd) => {
  const projectStore = useProjectStore.getState()
  await projectStore.refresh()

  // Try to detect a project from the launch CWD
  const detected = await invoke<DetectedProject | null>('detect_project', { path: launchCwd })

  if (detected) {
    // Check if this git root matches a known project
    const known = Object.values(projectStore.projects).find(p => p.path === detected.gitRoot)
    if (known) {
      await projectStore.setActiveProject(known.id)
    } else {
      // Auto-create project from detected git repo
      const newProject = await projectStore.addProject(detected.gitRoot, detected.suggestedName)
      await projectStore.setActiveProject(newProject.id)
    }
  } else {
    // No git repo — check for persisted activeProjectId (desktop launch)
    const persisted = projectStore.activeProjectId
    if (persisted && persisted !== 'scratchpad' && projectStore.projects[persisted]) {
      await projectStore.setActiveProject(persisted)
    } else {
      await projectStore.setActiveProject('scratchpad')
    }
  }
})
```
